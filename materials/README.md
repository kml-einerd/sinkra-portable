# Materiais Sínkra — precedência e uso

Este índice impede que uma reconstrução histórica seja confundida com a regra
operacional atual.

## Precedência

1. `AGENTS.md` e `PROMPT.md` governam ativação e retomada.
2. `skills/*/SKILL.md` e `skills/_shared/` governam método e contratos.
3. `00-visao-canonica-sinkra.md` explica a visão atual sem substituir skills.
4. Materiais calibrados e exemplos aprofundam decisões específicas.
5. Materiais históricos e fontes preservam a evolução e nunca prevalecem.

Em conflito, usar o item de menor número desta lista e registrar o conflito.

## Catálogo

| Arquivo | Status | Usar para |
|---|---|---|
| `00-visao-canonica-sinkra.md` | canônico explicativo | compreender o sistema completo |
| `01-sistema-de-elicitacao-e-controle.md` | histórico v0.1 | rastrear a primeira reconstrução |
| `02-avaliacao-e-arquitetura-do-pack.md` | histórico v0.1 | entender decisões intermediárias |
| `03-especificacao-v1-do-pack.md` | substituído | auditar a evolução; não executar |
| `04-interacao-guiada-de-decisoes.md` | calibrado | interação humana e decisões atômicas |
| `05-valor-extraido-das-falas-de-pedro.md` | complementar | teses, riscos e hipóteses de valor |
| `06-playbook-engenharia-de-prompts-sinkra.md` | canônico explicativo | construir prompts e waves |
| `07-prompt-reconstrucao-e-extracao-de-nos.md` | template | iniciar AS-IS e nós em material volumoso |
| `examples/` | exemplo ratificado/candidato | ver a gramática aplicada de ponta a ponta |
| `sources/` | fonte primária | contestar ou aprofundar uma afirmação |

## O que não foi copiado

O acervo `synkra-brain` possui vídeos, executáveis, caches, frames e análises
intermediárias que não são necessários em runtime. As notas extensas das aulas
têm 72 referências visuais ausentes no acervo original; seus conceitos úteis
foram consolidados na visão canônica, nas skills e nos materiais 01–02.

O pacote deve continuar pequeno: adicionar uma fonte bruta somente quando uma
skill ou afirmação canônica não puder ser executada ou auditada sem ela.
