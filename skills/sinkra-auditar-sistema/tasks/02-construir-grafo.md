# Task 02 — Construir grafo

Criar arestas:

- skill chama task;
- task consome input e produz output;
- output alimenta consumidor;
- checklist verifica critério;
- gate autoriza transição;
- executor realiza task;
- decisão sustenta regra;
- arquivo referencia arquivo.

Detectar referências inexistentes, órfãos, ciclos, fan-in sem owner e caminhos
que terminam sem output persistido.

## Output

Grafo ou tabela de adjacência com findings reproduzíveis.
