# Task 05 — Publicar auditoria

1. Preencher
   [audit-report.md](../../_shared/templates/audit-report.md).
2. Citar paths, objetos e evidências suficientes para reproduzir.
3. Separar confirmado, provável e não verificado.
4. Registrar gaps de cobertura.
5. Definir gate de encerramento e ordem de reparo.
6. Persistir versão da auditoria e handoff.

## Aceitar

Outro executor consegue reproduzir cada finding e iniciar a primeira
remediação sem interpretar a intenção do auditor.
