# Task 02 — Classificar domínio

## Objetivo

Determinar quem possui autoridade epistemológica para cada dimensão ainda
classificada como `decisão humana` ou `conflito`.

## Executar

Não perguntar sobre item resolvido ou não bloqueante. Para cada gap humano,
perguntar:

> Você domina este assunto o suficiente para definir as regras e avaliar os
> trade-offs?

Registrar `sim`, `não` ou `parcial`, sem inferir a resposta pela confiança da
fala. Quando parcial, listar dimensões dominadas e desconhecidas.

Separar:

- fonte de conhecimento;
- decisor;
- reviewer;
- accountable;
- dono do gate.

Uma pessoa pode acumular papéis, mas as responsabilidades devem permanecer
visíveis.

## Aceitar

A rota de elicitação, pesquisa ou híbrida está explícita e cada dimensão
crítica possui uma fonte ou um gap.
