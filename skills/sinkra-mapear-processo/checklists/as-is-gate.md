# Gate — AS-IS

- [ ] início, fim, owner e entidade raiz definidos
- [ ] narrativa bruta preservada
- [ ] fontes possuem localização, versão e validade
- [ ] entidades possuem identidade e lifecycle
- [ ] stages não são status de task
- [ ] tasks possuem verbo, executor, input, output e consumidor
- [ ] exceções, loops, falhas, esperas e retornos aparecem
- [ ] hipóteses, gaps e conflitos estão rotulados
- [ ] responsável validou o escopo e a versão
- [ ] melhorias estão separadas em TO-BE candidates
