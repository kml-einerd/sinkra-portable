# Task 03 — Extrair modelo candidato

1. Extrair substantivos candidatos a entidades.
2. Identificar identidade, nascimento, morte e lifecycle.
3. Separar stages da entidade de status das tasks.
4. Extrair verbos como tasks candidatas.
5. Contratar input, transformação, output, executor e consumidor.
6. Mapear transições, relações, loops, esperas e retornos.
7. Vincular cada elemento à evidência ou marcá-lo como hipótese/gap.

## Output

Mapa candidato no formato de
[process-map.yaml](../../_shared/templates/process-map.yaml).

Não fundir objetos apenas porque possuem nomes parecidos.
