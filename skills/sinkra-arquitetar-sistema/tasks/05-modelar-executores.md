# Task 05 — Modelar executores

Carregar e executar
[sinkra-modelar-executores](../../sinkra-modelar-executores/SKILL.md) sobre as
tasks do TO-BE.

## Executar

1. Classificar cada task por natureza do trabalho.
2. Decompor tasks que misturam regra, interpretação e responsabilidade.
3. Contratar Workers determinísticos.
4. Contratar Agentes somente para interpretação contextual.
5. Definir papéis humanos, reviewers, accountables e gate owners.
6. Desenhar handoffs e fan-in quando houver múltiplos executores.

## Output

Registry de executores, assignments, contratos e gaps de capacidade.
