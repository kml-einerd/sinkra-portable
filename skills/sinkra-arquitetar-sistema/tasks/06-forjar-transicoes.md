# Task 06 — Forjar skills de transição

Para cada transição aprovada, carregar e executar
[sinkra-forjar-skill](../../sinkra-forjar-skill/SKILL.md).

## Executar

1. Priorizar uma transição pequena e valiosa.
2. Aplicar `reuse > adapt > create`.
3. Criar `SKILL.md` orquestrador, tasks, checklists e referências.
4. Preservar contratos de input, output, executor, gate e persistência.
5. Forward-testar a transição sem contexto vazado.
6. Promover a próxima transição somente após corrigir a anterior.

## Output

Skills de transição versionadas e uma matriz de cobertura do lifecycle.

Não criar full cycle enquanto os componentes ainda falharem isoladamente.
