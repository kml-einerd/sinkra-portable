# Task 03 — Desenhar orquestração

1. Calibrar atomicidade das tasks.
2. Definir rota fixa, condicional ou paralela.
3. Contratar ordem, dependências, tasks não aplicáveis e fan-in.
4. Definir contexto mínimo por task.
5. Separar acceptance criteria, checklist e gate.
6. Definir blockers, warnings, retry, cancelamento e rollback.
7. Definir state, checkpoint, resume, output e handoff.
8. Calibrar liberdade:
   - alta para heurística contextual;
   - média para padrão com parâmetros;
   - baixa para operação frágil ou determinística.

## Output

Grafo da skill e contratos de cada task.
