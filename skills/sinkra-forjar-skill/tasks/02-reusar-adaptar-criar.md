# Task 02 — Reusar, adaptar ou criar

1. Inventariar skills, tasks, Workers, templates e contratos existentes.
2. Comparar objetivo, input, output, risco, executor e gate.
3. Escolher:
   - `REUSE` quando o contrato é compatível;
   - `ADAPT` quando a transformação é a mesma e o contexto difere;
   - `CREATE` quando a capacidade não existe ou a adaptação quebraria o
     contrato.
4. Registrar decisão e evidência.

Nome semelhante não comprova compatibilidade. Não criar componente novo apenas
para trocar linguagem ou persona.
