# Task 06 — Registrar e entregar

1. Executar o gate de forja.
2. Persistir versão, origem, decisão de reuso e dependências.
3. Registrar casos executados, falhas e limitações.
4. Registrar a capacidade em `sinkra-work/registry/` ou no registry já declarado
   pelo projeto.
5. Criar handoff com path, gatilho, input mínimo e próximo teste.
6. Marcar como candidata até obter runs reais.

Não declarar autonomia ou estabilidade a partir de um único forward-test.
