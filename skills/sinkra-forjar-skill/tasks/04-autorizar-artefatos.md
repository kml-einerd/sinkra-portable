# Task 04 — Autorizar artefatos

1. Criar `SKILL.md` com frontmatter mínimo e descrição de gatilho precisa.
2. Manter `SKILL.md` abaixo de 500 linhas e sem README, changelog ou guia de
   instalação dentro da skill.
3. Manter somente rota, regras, gates e navegação no orquestrador.
4. Criar um arquivo por task atômica.
5. Criar checklists apenas para verificações executadas.
6. Mover schemas, políticas e conhecimento para referências.
7. Criar script somente para lógica repetitiva ou determinística.
8. Adicionar metadados específicos do host em subpastas opcionais.
9. Usar links relativos e evitar referência profunda.

Não duplicar conteúdo entre `SKILL.md`, tasks e referências.
