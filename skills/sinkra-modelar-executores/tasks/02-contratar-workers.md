# Task 02 — Contratar Workers

Para cada Worker:

1. Definir transformação determinística e limites.
2. Contratar inputs, schema, versões e ausência.
3. Definir comando, função ou interface.
4. Contratar outputs, códigos de falha e destino.
5. Definir teste mínimo, idempotência, timeout e rollback.
6. Definir logs sem expor segredos.

## Bloquear

Não criar Worker quando a regra ainda depende de interpretação não modelada.
