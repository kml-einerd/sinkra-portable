# Task 01 — Classificar tasks

Para cada task validada:

1. Confirmar verbo, input, output, critério, risco e consumidor.
2. Identificar decisão humana, regra determinística e interpretação contextual.
3. Decompor quando houver mais de um objetivo ou natureza.
4. Classificar executor principal e justificar.
5. Marcar reviewer, accountable e gate owner.

## Output

Matriz `task → natureza → executor → autoridades → justificativa`.
