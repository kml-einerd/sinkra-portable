# Gate — Executores

- [ ] cada task possui um verbo e um executor principal
- [ ] trabalho misto foi decomposto ou possui handoff explícito
- [ ] Workers possuem regra, interface, teste e falhas
- [ ] Agentes possuem método, fontes, limites e escalonamento
- [ ] papéis humanos dizem qual decisão ou risco controlam
- [ ] reviewer e accountable estão separados do executor quando necessário
- [ ] paralelismo possui independência e owner do fan-in
- [ ] outputs e consumidores são compatíveis
- [ ] permissões seguem menor privilégio
- [ ] não existe persona sem task contratada
